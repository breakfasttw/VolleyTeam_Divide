# 排球分隊器

## 功能概述

- 輸入人名、性別，簡單選擇模式後，由系統自動分組配對並安排上場順序
- 目的是可以跟不同的人同隊、跟不同人對戰、讓大家上場時間相似

## 系統框架

- 最終會推送到 Github 部署
- 手機優先的響應式網頁
- 盡量使用純前端語法，運算邏輯可使用 python 或 js
- 不寫入記憶體，但同一瀏覽器可寫入 local storage，力求下次開啟網頁時仍可保留已輸入的資訊 (除非更換瀏覽器或清除 Cookie)
- 深色模式

## 前端操作概述

- 設定 > 輸入 > 開始分隊 > 檢視分隊結果

### 設定區

- 輸入「打場名稱」，選填
    - text，上限 20 個字
- 選擇「打球時間」，必填
    - 預設 3.0 小時
    - 時間格式為小時，以 0.5 為單位的數字選項，min = 0.5，max = 6.0
- 選擇「是否把男生打散】，必填
    - radio button
    - 預設勾選【是】
- 選擇「幾個人一小隊」，必填
    - 預設「2人」
    - 選項：1人、2人、3人、6人

### 輸入區

- 最上方用一行文字即時計算人數
    - 「目前共 {x} 人參與， {y} 女 {x} 男」
- 【小組區塊】
    - 根據「幾個人一小隊」，決定此輸入區的【小組區塊】有幾個【人員容器】
    - 例如：2 人一小隊，總【小組區塊】最多會有 12 個，每個【小組區塊】內會有 2 個 【人員容器】
        - 預設先展開可供 12 個【人員容器】填寫的【小組區塊】數量，即此範例預設展開 6 個【小組區塊】
        - 使用者可點擊【新增小組】依序展開第 7、8...12 個【小組區塊】
        - 每個【小組區塊】前面顯示小組編號
            - 從 1 開始，假如中途有刪除小組，則編號重新排序 (務必連號)
    - 同一個 【小組區塊】 的人員，每次上場會綁再一起，不會被拆散
    - 允許同一個【小組區塊】沒有輸入滿
- 【人員容器】
    - 總 【人員容器】 上限 24 人
    - 填寫「人員名稱」：
        - text，字數上限 20
        - 必填
    - 選擇「生理性別」：
        - radio button (男、女)
        - 必填，預設女

### 開始分隊

- 驗證：是否有相同人員
    - 如果場上有完全相同的「人員名稱」+「生理性別」，就跳提示
        - "注意：{人員名稱}({生理性別}) 同時出現在 小組{m} 和 小組{n}，是否仍要分隊?"
            - 範例：「注意：王小明(男) 同時出現在 小組 2 和 小組 5，是否仍要分隊?』
        - 選擇【仍要分隊】>> 後續將該為重複的 {人員名稱}尾綴其所在的小組編號。例如：王小明2、王小明5
        - 選擇【返回修改】>> 不分隊，退回編輯畫面
- 驗證：輸入區人數是否足夠
    - 如果輸入區的總 【人員容器】 小於 6 人：則跳提示「人數過少無法分隊 (〒︿〒) <br> 再多揪點人!」
    - 只能點擊【好吧 ┐(´д`)┌】按鈕 >> 退回編輯畫面
- 分隊運算時，背景用半透明黑色遮罩避免使用者點擊，並顯示過場動畫與文字

## 分隊邏輯

- 一場比賽大約 10~20 分鐘
- 正規回合 25 分勝
- 備選回合 15 分勝
