# 排球分隊器

## 功能概述

- 輸入人名、性別，簡單選擇模式後，由系統自動分組配對並安排上場順序
- 目的是可以跟不同的人同隊、跟不同人對戰、讓大家上場時間相似

## 系統框架

- 最終會推送到 Github 部署
- 手機優先的響應式網頁
- 盡量使用純前端語法，運算邏輯可使用 python 或 js
- 不寫入記憶體，但同一瀏覽器可寫入 local storage，力求下次開啟網頁時仍可保留已輸入的資訊
- 深色模式

## 前端操作概述

- 設定 > 輸入 > 開始分隊 > 檢視分隊結果

### 設定區

- 輸入「打場名稱」，選填
    - text，上限 20 個字
- 選擇「打球時間」，必填
    - 預設3小時
    - 0.5 為單位的數字選項，min = 0，max = 24
- 選擇「是否把男生打散】，必填
    - radio button
    - 預設勾選【是】
- 選擇「幾個人一小隊」，必填
    - 預設「2人」
    - 選項：2人、3人、6人

### 輸入區

- 根據「幾個人一小隊」，決定此輸入區的【小組區塊】有幾個【人員容器】
    - 例如：2 人一小隊，總【小組區塊】最多會有 15 個，每個【小組區塊】內會有 2 個 【人員容器】
- 總 【人員容器】 上限 24 人
- 完成人員名稱、性別輸入以及相關設定，點擊「開始分隊」

## 分隊邏輯

- 一場比賽大約 10~20 分鐘
- 正規回合 25 分勝
- 備選回合 15 分勝
